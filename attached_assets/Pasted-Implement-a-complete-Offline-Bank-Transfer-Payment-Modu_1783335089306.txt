Security

* UTR Number must be unique.
* Prevent duplicate UTR submissions.
* Validate payment amount.
* Secure file uploads.
* Maintain complete audit logs.
* Record verification date, time, and admin name.

Allow the admin to edit bank details without changing the code:

* Bank Name
* Branch
* Account Name
* Account Number
* IFSC Code
* Swift Code (Optional)
* UPI ID

Changes should automatically appear on the customer payment page.

⸻

Final Objective

Build a secure, production-ready Offline Bank Transfer Payment System where customers can pay via NEFT, RTGS, IMPS, Cash Deposit, or Bank Transfer, submit their UTR number and payment proof, and have the payment verified by the admin. After approval, the system should automatically generate invoices, update booking status, and send notifications via WhatsApp, SMS, Email, and the customer dashboard. This module should integrate seamlessly with the existing booking workflow and require no manual coding for future bank detail updates.
