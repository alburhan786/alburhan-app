PRODUCTION CHANGE REQUEST – CUSTOMER DASHBOARD INVOICE LOGIC

This is a production-critical financial workflow. Follow these instructions exactly.

OBJECTIVE

The Customer Dashboard must NEVER show Pending or Unpaid invoices.

Only invoices with actual payments received should be visible to customers.

====================================================
RULES
====================================================

1. DO NOT display any invoice in the Customer Dashboard if:

- Status = Pending
- Status = Unpaid
- Status = Awaiting Payment
- Status = Payment Link Sent
- Amount Paid = 0
- Payment Verification Pending
- Payment Failed

These invoices must remain completely hidden from the customer dashboard.

====================================================
SHOW ONLY PAID INVOICES
====================================================

Display an invoice ONLY when at least one successful payment has been recorded.

Examples:

✔ Partially Paid
✔ Advance Paid
✔ 50% Paid
✔ Balance Paid
✔ Fully Paid
✔ Paid

Only these invoices should appear.

====================================================
PAYMENT FLOW
====================================================

Booking Submitted
↓

↓
Customer Dashboard
(NO invoice visible)
↓

↓
Customer Pays

↓
Invoice Generated / Updated
↓
Invoice PDF Generated
↓
Invoice appears in Customer Dashboard
↓
WhatsApp + Email + SMS + RCS sent

====================================================
DASHBOARD RULES
====================================================

Before payment:

Hide:
• Invoice Card
• Invoice PDF
• Download Invoice
• Share Invoice
• Invoice Number
• Tax Invoice
• Balance Invoice

After payment:

Automatically show:

✓ Invoice Number
✓ Invoice Date
✓ Payment Status
✓ Amount Paid
✓ Balance
✓ Download PDF
✓ Share PDF
✓ Payment History
✓ GST Details
✓ Receipt

====================================================
API LOGIC
====================================================

Filter invoices using payment status.

Never return pending invoices to the customer dashboard API.

Only return invoices where:

amountPaid > 0

OR

paymentStatus IN

PARTIAL
PARTIALLY_PAID
ADVANCE_PAID
PAID
FULLY_PAID

====================================================
SECURITY
====================================================

Customers must never access pending invoice PDFs via URL.

Pending invoices should not be downloadable.

Pending invoices should not be searchable.

Pending invoices should not appear in browser history.
