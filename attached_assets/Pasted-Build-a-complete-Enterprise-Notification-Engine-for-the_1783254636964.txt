Build a complete Enterprise Notification Engine for the Al Burhan Tours & Travels ERP.

IMPORTANT:
Do not break any existing modules.

The Notification Engine must become a central service used by all ERP modules.

==================================================
ARCHITECTURE
==================================================

Every ERP event should create one Notification Event.

Example:

Booking Created
        │
        ▼

        │
