Booking ID must be generated automatically in the format:
ABT + Current Year + 6-digit random number
Example:
ABT26078035

SYSTEM REQUIREMENTS
-----------------------------------

Automatically trigger notifications immediately after admin approves the booking.

Store notification history in the database.

Retry failed WhatsApp, SMS and Email notifications up to 3 times.

Display delivery status:

✓ WhatsApp Sent
✓ SMS Sent
✓ Email Sent
✓ Dashboard Notification Sent

If any notification fails, show the failure reason in the admin panel and allow manual resend.

Do not require any manual button clicks after booking approval. Everything must run automatically in the background.
