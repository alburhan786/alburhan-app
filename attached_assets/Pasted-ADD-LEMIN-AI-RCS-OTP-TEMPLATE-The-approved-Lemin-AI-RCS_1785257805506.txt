Use one central OTP template mapping and do not duplicate hardcoded template IDs.

Required variables:

- customer_name or user_name
- otp
- expiry_minutes
- purpose
- support_phone

Before sending:

1. Generate a secure random OTP.
2. Store only a hashed OTP in the database.
3. Set an expiry time, preferably 5 minutes.
4. Limit verification attempts.
5. Add resend cooldown and rate limiting.
6. Never log the OTP, API key or full provider request.
7. Never send an empty or unreplaced variable.
8. Use template ID 3663 only for OTP/login verification events.

Send through Lemin AI using:

POST /api/send/template

Payload requirements:

- type: single
- dial_code: process.env.LEMIN_DIAL_CODE
- template: 3663
- phone: recipient mobile number without country code, spaces or symbols
- user_id: process.env.LEMIN_API_KEY
- variables: use the exact variable names required by approved template 3663
