PRODUCTION SMS ROUTING POLICY (FINAL)

The Emergency SMS Fallback feature has been added successfully.

Now update the notification system so it follows these production rules.

====================================================
PRIMARY SMS ROUTE
====================================================

Fast2SMS DLT Route is the ONLY production SMS route.

Always use:

• Approved DLT Sender ID
• Approved DLT Template
• DLT API
• DLT Route

Quick SMS must NEVER be selected automatically.

====================================================
EMERGENCY FALLBACK
====================================================

Emergency SMS Fallback must remain OFF by default.

Only Super Admin can enable it manually.

Settings →

SMS Configuration →

Emergency SMS Fallback

Default:

OFF

When OFF

Every notification must use ONLY:

✓ Fast2SMS DLT Route

If DLT fails:

• Do NOT automatically switch to Quick SMS.
• Continue sending WhatsApp and Email.
• Record the failure in Notification Logs.
• Show the exact provider error.

====================================================
WHEN EMERGENCY MODE IS ENABLED
====================================================

Quick SMS may be used ONLY after a Super Admin manually enables Emergency Mode.

Before enabling, display:

WARNING

You are switching from the approved DLT route to Emergency SMS.

This should only be used during provider outages.

Require confirmation.
