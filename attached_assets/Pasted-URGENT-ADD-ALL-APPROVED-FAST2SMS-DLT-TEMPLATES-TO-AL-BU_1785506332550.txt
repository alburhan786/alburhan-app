==================================================
DOCUMENT DOWNLOAD LINK REQUIREMENTS
==================================================

For invoice, agreement, visa and ticket:

1. Generate a secure HTTPS public URL.
2. The URL must open on a mobile browser without admin login.
3. Use a signed or tokenized link.
4. The token should expire according to system settings.
5. Do not send localhost, Replit development URLs, internal file paths or private storage URLs.
6. Prefer short URLs on the Al Burhan domain, such as:

https://alburhantravels.com/d/i/secure-token
https://alburhantravels.com/d/a/secure-token
https://alburhantravels.com/d/v/secure-token
https://alburhantravels.com/d/t/secure-token

7. Verify that every URL downloads or opens the correct PDF.

==================================================
NOTIFICATION FALLBACK
==================================================

For transactional notifications:

Primary: SMS via Fast2SMS DLT
Secondary: WhatsApp
Third: Email

Do not mark an SMS as delivered merely because the provider API returns success.

Use statuses:

- queued
- submitted
- sent
- delivered
- failed
- rejected
- expired

Store the provider request ID and periodically check delivery status.
