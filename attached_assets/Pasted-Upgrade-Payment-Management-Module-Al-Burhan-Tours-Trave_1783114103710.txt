Upgrade Payment Management Module – Al Burhan Tours & Travels ERP

Upgrade the existing Payment Analytics page into a complete enterprise-grade Payment Management System without deleting or breaking any existing features, bookings, database records, or integrations.

Core Requirements

1. Payment Management

Implement full payment management with:

* Add Payment
* Edit Payment
* Soft Delete Payment
* Restore Deleted Payment
* View Payment Details
* Print Receipt
* Download PDF Receipt
* Email Receipt
* WhatsApp Receipt

Never permanently delete payment records.

⸻

2. Payment Actions

Add an Actions column in the payment table with:

* ✏️ Edit
* 🗑️ Soft Delete
* 👁️ View
* 📄 Print Receipt
* 📥 Download PDF
* 📧 Email Receipt
* 📱 WhatsApp Receipt
* 📜 Payment History

⸻

3. Edit Payment

Allow editing:

* Payment Amount
* Payment Date
* Payment Mode
* Transaction ID
* Bank Name
* Cheque Number
* UPI Reference
* Notes
* Received By

Automatically update:

* Total Paid
* Remaining Balance
* Booking Status
* Invoice Status

⸻

4. Soft Delete

Never permanently remove payment records.

When deleting:

* Confirmation popup
* Require Super Admin permission
* Ask for deletion reason
* Mark payment as Deleted
* Save Deleted By
* Save Deleted Date
* Save Deletion Reason
* Allow Restore

⸻

5. Payment History

Maintain complete audit logs:

* Original Amount
* Edited Amount
* Previous Balance
* New Balance
* Modified By
* Date & Time
* Action Type
* Reason for Change

⸻

6. Booking Integration

Each booking must display:

* Package Cost
* GST
* Discount
* Total Amount
* Advance Paid
* Total Paid
* Remaining Balance
* Outstanding Amount
* Refund Amount
* Complete Payment Timeline

Whenever a payment is added, edited, deleted, or restored, automatically recalculate booking balances.
