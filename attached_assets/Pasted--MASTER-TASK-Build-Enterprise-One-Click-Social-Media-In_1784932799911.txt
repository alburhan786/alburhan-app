# MASTER TASK: Build Enterprise One-Click Social Media Integration Hub (OAuth)

## Objective

Redesign the entire Social Media Integration module into an enterprise-grade Integration Center similar to Shopify, HubSpot, Zoho CRM, Salesforce, and modern SaaS platforms.

The goal is ZERO technical configuration for customers.

Users should NEVER have to manually enter:

- App ID
- App Secret
- Page Access Token
- Verify Token
- Webhook URL
- Business Account ID
- Instagram ID
- Page ID

Everything should be configured automatically through OAuth.

This feature will be sold commercially to travel agencies, so it must be production-ready, scalable, secure, and extremely easy to use.
