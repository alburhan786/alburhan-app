Replit Agent Prompt – Complete API Settings & Communication Center Integration

I want to complete the API integration for my Al Burhan Tours & Travels ERP Communication Center.

Objective

Build a secure API Settings module where I can configure all third-party providers directly from the Admin Panel without editing .env files manually.

⸻

Create a new menu

Admin → Settings → API Settings

Only Super Admin can access this page.

⸻

Supported Providers

1. BotBee WhatsApp

Fields:

* Provider Name
* Base URL
* API Key
* Business Phone Number
* Instance ID (if applicable)
* Webhook URL (optional)

Buttons:

* Save
* Test Connection
* Send Test WhatsApp

When “Test Connection” is clicked:

* Validate API credentials
* Display Connected / Failed
* Show provider response

When “Send Test WhatsApp” is clicked:

Ask for a mobile number and send a real WhatsApp message.

⸻

Fields:

Buttons:

* Save

Security

* Encrypt all API keys before storing in the database.
* Never expose secrets in the frontend.
* Show only the last 4 characters of each key (e.g. ********ABCD).
* Add a Show/Hide toggle while editing.
* Log all changes with admin name, date, time, and IP.
* Allow only Super Admin to edit.
