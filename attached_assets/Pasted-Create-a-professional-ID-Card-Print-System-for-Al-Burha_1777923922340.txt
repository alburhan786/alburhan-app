Create a professional ID Card Print System for Al Burhan Tours & Travels.

OBJECTIVE:
When admin clicks PRINT → system should generate a PDF with:
- Front side of ID card (Mohammed Altaf)
- Back side of SAME ID (Mohammed Altaf)
- Ready for duplex printing (front + back alignment)

-------------------------------------
CARD SETTINGS
-------------------------------------
- Card size: 86mm x 54mm
- DPI: 300
- Margin: 5mm
- Page: A4

-------------------------------------
PRINT LAYOUT (VERY IMPORTANT)
-------------------------------------

PAGE 1 (FRONT SIDE):
- Show ID card FRONT design
- Center aligned
- Option: multiple cards grid (optional)
- Example: Mohammed Altaf FRONT

PAGE 2 (BACK SIDE):
- Show SAME ID BACK design
- EXACT SAME POSITION as front
- Example: Mohammed Altaf BACK

⚠️ IMPORTANT:
Front and Back must be perfectly aligned for duplex printing.

-------------------------------------
DATA BINDING
-------------------------------------

When printing:
- Use SAME user ID
- Fetch:
  name
  photo
  passport
  mobile
  QR code
  ID number

Example:
{

  id: "ABT-001",
  role: "Airport Staff",
  mobile: "+91 9893989786"
}
