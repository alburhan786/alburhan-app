2. Migration Verification

Verify that every required migration has run successfully.

* Run the migration.
* Restart the API.
* Verify again.

3. Admin SMS Template Manager

* View templates
* Edit template
* Enable/Disable

Provide screenshots.

4. Live SMS Test

* Generate the exact request.
* Send a live SMS.
