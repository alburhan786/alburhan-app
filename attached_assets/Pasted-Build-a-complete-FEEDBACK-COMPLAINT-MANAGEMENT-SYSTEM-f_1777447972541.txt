2) FRONTEND (CUSTOMER SIDE)
----------------------------------------

Create public page:
URL: /feedback?booking_id=XXXX

Flow:
1. User enters mobile number
2. Send OTP
3. Verify OTP
4. Fetch pilgrim data (auto-fill name + booking)
5. Show feedback form

Form Fields:
- Name (read-only)
- Booking ID (read-only)
- Rating (1–5 stars)
- Service Type (dropdown)
- Comment (text)
- Complaint? (checkbox)

Rules:
- If rating <= 3 → auto set is_complaint = true
- Prevent multiple submissions per booking (1 per pilgrim)
